# Windows 后台 0.1.4+5（2026-09-21）

## 打开方法

关闭旧后台，打开本包“文殊计数器后台管理”文件夹中的 huideng_admin.exe。请保留整个文件夹，不要只复制 EXE。无需卸载旧版，不影响手机和云端数据。

此包是 Windows x64 Release 便携版，含所需 DLL；未使用 Windows Authenticode 代码签名。

## 最新入口

- App版本：新增/编辑版本、HTTPS 下载地址、更新说明、字节数、SHA-256、发布时间、正式发布开关、强制更新开关、单独发送更新通知。
- 公共网盘：列表、搜索、上传/下载及文件类型限制设置、管理员删除。
- 用户资源用量：存储与上传统计、筛选、个人配额/等级、限制、警告等；不能精确取得的下载流量仍显示未知。
- 结缘管理、群聊管理、藏历配置、用户、论坛/文章等已有入口一并打包。

本轮手机端字号、阅读、地名解析等属于客户端逻辑，不伪造后台开关；不是所有手机修改都能由后台下发。

## 必须核对的服务器接口

生成后台程序不等于部署服务器。此轮未修改线上 Supabase。

此前记录：058 版本管理迁移已执行；新版 releases.* admin-api 尚未部署。

操作：Supabase → Edge Functions → admin-api → Code → index.ts。用本包“服务端部署/dashboard-admin-api.ts”的全部内容替换，再部署。不要粘贴 functions/admin-api/index.ts 的分文件版本，以免缺少 connection_signer.ts。

已经成功执行的迁移不要盲目重复执行。登录新后台后，先检查 App版本、公共网盘、用户资源用量是否能正常读取；如报错，记录原文再核对服务端部署。

## 手机更新测试

不通过 USB/ADB 更新手机。本次没有生成手机 APK。

当前手机 1.0.47 是测试签名；正式包不能覆盖安装。当前版本发布接口面向全体用户，没有独立测试用户/签名渠道，不要将测试签名 APK 打开“正式发布”。定向测试渠道需要另行补齐。

发布正式更新需要：同一包名、同一正式签名、更高 versionCode、真实 APK 下载链接（不是网页分享页）、准确大小及 SHA-256。建议关闭强制更新；“发送更新通知”与保存是独立操作。

手机入口：计数 → 设置 → 更新版本 → 检查更新。最终安装由用户在 Android 系统确认。
