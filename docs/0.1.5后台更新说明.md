# 后台 0.1.5：选择 APK 自动填版本记录

## 操作

1. 打开新版后台，登录管理员账号 → App版本 → 新增版本。
2. 点击“选择 APK 并自动填写”，选择本机 APK。程序读取真正的 versionName/versionCode、包名和字节数，流式计算 SHA-256，然后通过公共网盘分块上传并等待服务器完整性校验。
3. 上传成功后下载地址自动填好；你只需写更新说明、核对发布开关，然后保存。

本机原 APK 不会删除。失败点击重试，不需再次选择。关闭后台后重新选择同一文件会复用保存在本机的上传标识和续传地址。进度只保存地址/标识，不保存登录令牌。

选择后上传的文件按照公共网盘现有规则公开；保存版本记录与正式发布仍是独立选择，默认不正式发布、不强制更新。测试签名包不要作为全体正式用户更新发布。

## 需更新一个下载接口

本次未部署线上 Edge Function。要让自动填入的固定下载地址生效，请：

Supabase → Edge Functions → resource-web → Code → index.ts

用本包“服务端部署/resource-web-dashboard.ts”的全部内容替换并部署，沿用该公开下载函数当前访问配置。

不要替换到 public-resources 或 admin-api 中。无需执行新的 SQL。原先版本管理 admin-api 尚未更新的，仍需要部署随包 dashboard-admin-api.ts 到 admin-api/index.ts。

固定地址调用 resource-web，参数 redirect=1。每次先由原 public_resource_web_resolve 检查公开状态、下架状态、下载开关和限额，再 302 跳转到短期签名 Storage 地址。原有分享网页/JSON 接口继续有效。不直接公开 bucket，不绕过权限。

上传仍复用已部署 public-resources 的 TUS/complete/share 接口，管理员同样遵守现有文件大小、上传开关及配额；不能通过本窗口绕过限制。
