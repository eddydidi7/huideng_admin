# Windows 后台 0.1.3：论坛、文章、用户列表

原因：原管理端这三个栏目只有占位页，load() 没有调用查询接口。数据并未因此删除。

## 更新顺序
1. Supabase → SQL Editor → New query，复制执行 `supabase/migrations/202609190039_admin_catalog.sql`。该脚本仅新增只读查询接口，不修改用户和文章记录。
2. Supabase → Edge Functions → admin-api → Code，用 `supabase/functions/admin-api/index.ts` 的完整代码替换 index.ts，保留同目录的 connection_signer.ts，再部署更新。不要新建另一个函数，不要修改密钥设置。
3. 关闭旧版 Windows 管理程序，将新 ZIP 整体解压到新文件夹，运行 huideng_admin.exe，用原管理员账号登录。

## 栏目说明
- 论坛：现有红书的动态、图文、长文章。
- 文章：红书 post_kind=article 的长文章；过去按图文发布的内容仍在论坛。
- 用户：App 注册账号及访客账号，显示昵称、个人号、邮箱、注册时间和账号状态。不是后台管理员名单。
- 支持搜索、每页50条、详情和错误重试。不读取私人笔记和私密帖子，不改写记录。
- 普通 App 用户无查询权限；版主仅可查论坛；管理员及超级管理员可查这三个栏目。

本次没有在你的线上项目执行 SQL 或部署函数。完成上述云端更新前，新程序可能显示服务未就绪。
