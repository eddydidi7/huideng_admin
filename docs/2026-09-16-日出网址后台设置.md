# 日出网址后台设置

版本：后台 0.1.1+2；Android 用户端 1.0.7+8。

## 使用

打开新版后台，用原超级管理员账号登录，进入「系统设置」，修改「日出网址」，点击「保存入口网址」。必须填写完整 HTTPS 链接。

用户端联网启动、回到前台及前台每 5 分钟读取配置；离线继续使用本机缓存。全新安装或无有效配置时使用用户指定的 Daysfromdate 默认链接。此次更新安装后，之后单纯修改网址不再需要重编 App。
